# Templates

Ainda não subi os templates reais que uso (PRD, roadmap, sprint plan, brief de métricas etc.) — é a próxima leva de conteúdo do PM OS.

Enquanto isso, cada skill em `../skills/` já traz a estrutura do entregável correspondente dentro do próprio `SKILL.md`, então elas funcionam de forma independente. Quando os templates chegarem aqui, as skills vão referenciá-los diretamente em vez de descrever a estrutura inline.
